Arsitektur Basis Data

PostgreSQL tsrange & SELECT FOR UPDATE

Mencegah terjadinya reservasi ganda (*double booking*) dengan isolasi transaksi tingkat basis data. Slot yang terkunci tidak dapat diambil oleh koneksi paralel lain.

// Transaksi Penguncian Slot Atomik 15 Menit
BEGIN TRANSACTION ISOLATION LEVEL SERIALIZABLE;
SELECT id FROM barber_slots
WHERE barber_id = $1 AND slot_range && $2
FOR UPDATE NOWAIT;
// Eksekusi sukses status: pending_payment (15m)
